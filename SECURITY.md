# Security Policy

## Supported Versions

Security fixes are provided for the latest `1.x` release line.

## Reporting a Vulnerability

Please report vulnerabilities privately by email:

- `prateekbhujelpb@gmail.com`

Include as much detail as possible:

- affected version
- reproduction steps or proof of concept
- potential impact

Do not open public GitHub issues for unpatched vulnerabilities.

## Response Targets

- Initial response: within 72 hours
- Triage/update: within 7 days
- Patch release target: as quickly as possible based on severity
