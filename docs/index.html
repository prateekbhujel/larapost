LaraPost for Laravel

Ship social posts from one clean API

LaraPost gives you a single publish pipeline for Facebook, Instagram, Twitter/X, and LinkedIn, with account storage, scheduled posting, retry handling, and production-friendly command tooling.

Package: prateekbhujel/larapost Laravel: 10 / 11 / 12 / 13 PHP: 8.1+

Introduction

LaraPost is designed for teams who need reliable social publishing inside Laravel apps. It supports immediate publishes, scheduled dispatches, OAuth account onboarding, and controlled retries for transient API failures.

Installation

composer require prateekbhujel/larapost
php artisan larapost:install

Manual setup:

php artisan vendor:publish --tag=larapost-config
php artisan vendor:publish --tag=larapost-migrations
php artisan migrate

Quick Start

  1. Set provider credentials in .env.
  2. Connect at least one social account.
  3. Publish a test message.
  4. Enable cron for scheduled posts.
php artisan larapost:add-account facebook
php artisan larapost:test
* * * * * php /path/to/artisan larapost:run-scheduled >> /dev/null 2>&1

Configuration

Environment variables:

LARAPOST_DEFAULT_PLATFORM=facebook
LARAPOST_QUEUE_ENABLED=true
LARAPOST_MAX_RETRY_ATTEMPTS=3

FACEBOOK_APP_ID=
FACEBOOK_APP_SECRET=
TWITTER_CLIENT_ID=
TWITTER_CLIENT_SECRET=
LINKEDIN_CLIENT_ID=
LINKEDIN_CLIENT_SECRET=

Published config file: config/larapost.php

OAuth

Default endpoints:

  • GET /larapost/connect/{platform}
  • GET /larapost/callback/{platform}

Publishing API

Publish now:

use SocialSync\Facades\SocialMedia;

SocialMedia::post()
    ->content('Release update from LaraPost')
    ->platforms(['facebook', 'linkedin'])
    ->publish();

Schedule:

SocialMedia::post()
    ->content('Scheduled campaign message')
    ->platforms(['facebook', 'twitter'])
    ->scheduleFor(now()->addHours(2))
    ->publish();

Scheduler & Retry Strategy

The scheduled runner processes due posts and retries failures based on configured backoff. It claims rows before processing to reduce duplicate sends under concurrent workers. 

php artisan larapost:run-scheduled --limit=50

Command Reference

Command Purpose
larapost:install Publish config/migrations and prepare storage directories.
larapost:add-account {platform} Connect a provider account via OAuth flow.
larapost:test Publish a test post to active accounts.
larapost:run-scheduled Process due scheduled posts.

Deployment Checklist

  • Run migrations with --force.
  • Validate provider callback URLs in production.
  • Enable scheduler cron and monitor failed posts.
  • Keep package and provider APIs up to date.
* * * * * php /path/to/artisan larapost:run-scheduled >> /dev/null 2>&1

Troubleshooting

  • No active accounts matched: connect and activate at least one account.
  • OAuth callback failed: verify client credentials and callback URL registration.
  • Scheduled posts not running: verify cron execution and timezone assumptions.
  • Media upload failed: check allowed extensions and size limits.
