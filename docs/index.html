Production-Grade Social Publishing for Laravel

Laravel Social Sync unifies publishing workflows for Facebook, Instagram, Twitter/X, and LinkedIn. Built for real production teams with reliable scheduling, account encryption, and contributor-friendly tooling.

Stable: v1.1.1 Preview: 1.x-dev Laravel: 10 | 11 | 12 | 13 PHP: 8.1+

Overview

Use one fluent API to publish now or queue for later, while storing account credentials in your own database. The package ships with artisan commands, OAuth callbacks, retry/backoff strategy, and safe concurrent processing for scheduled jobs.

Unified Fluent API

SocialMedia::post() handles immediate and scheduled publishing across supported platforms.

Concurrency Safe Runner

Scheduled posts are atomically claimed before execution to prevent duplicate sends.

Open Source Ready

Includes CI, issue templates, release playbook, contribution guide, and security policy.

Installation

composer require prateekbhujel/laravel-social-sync
php artisan social-sync:install

Manual setup path:

php artisan vendor:publish --tag=social-sync-config
php artisan vendor:publish --tag=social-sync-migrations
php artisan migrate

Quick Start

  1. Configure OAuth credentials in .env.
  2. Connect at least one platform account.
  3. Send a test post.
  4. Enable cron for scheduled processing.
php artisan social-sync:add-account facebook
php artisan social-sync:test
* * * * * php /path/to/artisan social-sync:run-scheduled >> /dev/null 2>&1

Usage API

Publish immediately:

use SocialSync\Facades\SocialMedia;

$results = SocialMedia::post()
    ->content('Shipping v1.1.1 today')
    ->platforms(['facebook', 'linkedin'])
    ->publish();

Schedule for later:

SocialMedia::post()
    ->content('Scheduled campaign message')
    ->platforms(['facebook', 'twitter'])
    ->scheduleFor(now()->addHours(2))
    ->publish();

OAuth Flow

Connect routes are mounted under /social-sync by default:

  • GET /social-sync/connect/{platform}
  • GET /social-sync/callback/{platform}

You can customize prefix and middleware in config/social-sync.php.

Scheduling and Retries

The scheduled runner processes due posts, retries failures with configurable backoff, and permanently fails items after max attempts. Concurrency-safe claim logic prevents duplicate processing when multiple workers run together. 

php artisan social-sync:run-scheduled --limit=50

Configuration

Core environment variables:

SOCIAL_SYNC_DEFAULT_PLATFORM=facebook
SOCIAL_SYNC_QUEUE_ENABLED=true
SOCIAL_SYNC_MAX_RETRY_ATTEMPTS=3

FACEBOOK_APP_SECRET=

Production Deployment Checklist

  • Run migrations with --force during deploy.
  • Verify provider callback URLs match production domain.
  • Enable and monitor the scheduled runner cron.
  • Track failed posts and retry counts.
  • Keep to latest stable 1.x patch.

Monitoring and Observability

Capture failed publish responses and exception messages in your normal Laravel logging pipeline. Expose queue depth and failed post counts in your dashboard for proactive incident handling.

Troubleshooting

  • No active accounts matched: connect at least one active account for selected platform(s).
  • OAuth callback errors: verify client IDs/secrets and callback URL registration.
  • No scheduled publishes: confirm cron invocation and server timezone expectations.
  • Media upload issues: validate file type and size limits in package config.
