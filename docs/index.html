Production Package For Laravel

Unified social publishing API with scheduler, retries, and account onboarding

LaraPost gives your Laravel app one publish workflow for Facebook, Instagram, Twitter/X, and LinkedIn. It is built for real production usage: OAuth account connection, queued/scheduled posts, retry backoff, and command tooling for operations.

Package: prateekbhujel/larapost Laravel: 10 / 11 / 12 / 13 PHP: 8.1+ Branch Alias: 1.x-dev License: MIT

Overview

Single API

Use one fluent builder (`SocialMedia::post()`) for multiple providers.

Operational Safety

Scheduled runner atomically claims due jobs to avoid duplicate sends.

Contributor Friendly

Project includes release workflow, security policy, and contribution standards.

Production Tooling

CLI commands cover install, account linking, smoke tests, and scheduled execution.

Installation

composer require prateekbhujel/larapost
php artisan larapost:install

Manual setup (if you do not run the installer):

php artisan vendor:publish --tag=larapost-config
php artisan vendor:publish --tag=larapost-migrations
php artisan migrate

Quick Start

  1. Add provider credentials to .env.
  2. Connect at least one provider account.
  3. Publish test content.
  4. Enable cron for scheduled jobs.
php artisan larapost:add-account facebook
php artisan larapost:test
* * * * * php /path/to/artisan larapost:run-scheduled >> /dev/null 2>&1

Configuration

Core environment variables:

LARAPOST_DEFAULT_PLATFORM=facebook
LARAPOST_QUEUE_ENABLED=true
LARAPOST_MAX_RETRY_ATTEMPTS=3

FACEBOOK_APP_ID=
FACEBOOK_APP_SECRET=
FACEBOOK_API_VERSION=v20.0

TWITTER_CLIENT_ID=
TWITTER_CLIENT_SECRET=

LINKEDIN_CLIENT_ID=
LINKEDIN_CLIENT_SECRET=

Published config path: config/larapost.php

OAuth Onboarding

Default routes exposed by the package:

  • GET /larapost/connect/{platform}
  • GET /larapost/callback/{platform}

Publishing API

Publish immediately:

use SocialSync\Facades\SocialMedia;

SocialMedia::post()
    ->content('Release update from LaraPost')
    ->platforms(['facebook', 'linkedin'])
    ->publish();

Schedule for later:

SocialMedia::post()
    ->content('Scheduled campaign message')
    ->platforms(['facebook', 'twitter'])
    ->scheduleFor(now()->addHours(2))
    ->publish();

Scheduler and Retry Strategy

The scheduled runner processes pending due posts and applies configurable retry backoff. Use a one-minute cron to ensure reliable dispatch. 

php artisan larapost:run-scheduled --limit=50

Command Reference

Command Purpose
larapost:install Publish config/migrations and create storage directories.
larapost:add-account {platform} Connect a social account via OAuth.
larapost:test Smoke test publishing with active accounts.
larapost:run-scheduled Process due scheduled posts.

Deployment Checklist

  • Run migrations with php artisan migrate --force.
  • Verify provider callback URLs and production credentials.
  • Enable the scheduler cron for larapost:run-scheduled.
  • Monitor failures and retry count in `scheduled_posts`.
  • Track upstream API changes for each provider.
