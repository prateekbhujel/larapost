Introduction

LaraPost is Laravel-native social publishing infrastructure. It keeps provider accounts, OAuth credentials, publishing history, queues, scheduling, and business rules inside your Laravel application.

Meet LaraPost

LaraPost is built for applications that need social publishing as a product capability rather than as a separate browser-based SaaS. You can connect only the providers you need and publish through one Laravel-facing API.

The current 2.x line supports Facebook Pages, Twitter / X, LinkedIn member profiles, and TikTok Content Posting workflows. Publishing may happen immediately, through Laravel's queue, or at a scheduled time.

Requirements

  • PHP 8.3 or newer
  • Laravel 12 or 13
  • A Laravel-supported database
  • Provider developer credentials for each network you enable

Installation

Install LaraPost with Composer, run the installer, and verify the resulting application configuration before connecting production accounts.

composer require prateekbhujel/larapost
php artisan larapost:install
php artisan larapost:doctor

The installer lets you choose the publishing platforms, operator dashboard, and optional MCP integration instead of forcing every provider into the application.

Your first post

Once an account is connected, publishing uses the SocialMedia facade and fluent post builder:

use SocialSync\Facades\SocialMedia;

$result = SocialMedia::post()
    ->content('We just shipped a new release.')
    ->platform('facebook')
    ->publish();

Queues and scheduling

LaraPost can persist work before dispatch, use Laravel queues for asynchronous publishing, and keep future posts pending until they are due. Production applications must run the queue worker and Laravel scheduler when those features are enabled.

See Publishing for immediate, queued, scheduled, multi-platform, and account-targeted examples.

TikTok's safe default

TikTok uses TIKTOK_PUBLISH_MODE=upload by default. LaraPost transfers media to TikTok and the creator reviews and completes the post inside TikTok.

Direct Post is an explicit application-level opt-in because it requires current creator information plus explicit privacy, interaction, and consent choices.

AI-assisted workflows

The optional MCP server can expose selected LaraPost capabilities to compatible AI clients. It is disabled by default and must be authenticated when enabled. Coding agents working on the package can use the Agent Guide or llms.txt for the version-specific contract.
