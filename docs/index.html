Production-Grade Social Publishing for Laravel

Laravel Social Sync gives your app a single publish API for Facebook, Instagram, Twitter/X, and LinkedIn, with encrypted account storage, safe scheduling behavior, and contributor-ready release workflows.

Stable: v1.1.1 Preview: 1.x-dev Laravel: 10 | 11 | 12 | 13 PHP 8.1+

Overview

Use one fluent interface to publish instantly or queue posts for future delivery. The package includes OAuth connect routes, artisan tooling, retries with backoff, and atomic job claiming so multiple workers do not publish the same scheduled post twice.

Unified API

SocialMedia::post() supports immediate and scheduled publishing.

Safe Scheduling

Due rows are claimed atomically before processing to prevent duplicates.

OSS Ready

CI, issue templates, release docs, contribution process, and security policy included.

Installation

Install and bootstrap:

composer require prateekbhujel/laravel-social-sync
php artisan social-sync:install

Manual setup path:

php artisan vendor:publish --tag=social-sync-config
php artisan vendor:publish --tag=social-sync-migrations
php artisan migrate

Quick Start

  1. Configure OAuth provider credentials in .env.
  2. Connect at least one social account.
  3. Run a test publish.
  4. Enable cron for scheduled publishing.
php artisan social-sync:add-account facebook
php artisan social-sync:test
* * * * * php /path/to/artisan social-sync:run-scheduled >> /dev/null 2>&1

Usage API

Publish now:

use SocialSync\Facades\SocialMedia;

$results = SocialMedia::post()
    ->content('Shipping v1.1.1 today')
    ->platforms(['facebook', 'linkedin'])
    ->publish();

Schedule for later:

SocialMedia::post()
    ->content('Scheduled campaign message')
    ->platforms(['facebook', 'twitter'])
    ->scheduleFor(now()->addHours(2))
    ->publish();

OAuth Flow

Default connect routes:

  • GET /social-sync/connect/{platform}
  • GET /social-sync/callback/{platform}

Route prefix and middleware are configurable in config/social-sync.php.

Scheduling and Retries

The scheduled runner processes due rows, applies retry backoff, and marks permanent failures after max attempts. Job claiming is atomic, so parallel workers do not process the same row simultaneously. 

php artisan social-sync:run-scheduled --limit=50

Configuration

Core environment variables:

SOCIAL_SYNC_DEFAULT_PLATFORM=facebook
SOCIAL_SYNC_QUEUE_ENABLED=true
SOCIAL_SYNC_MAX_RETRY_ATTEMPTS=3

Production Deployment Checklist

  • Run migrations with --force in deploy pipeline.
  • Ensure provider callback URLs match production domain.
  • Enable cron for scheduled runner and monitor failures.
  • Track retries and failed publish responses in logs/alerts.
  • Stay on latest stable 1.x release.

Monitoring and Observability

Capture failed publish payloads and exceptions in your normal Laravel logging stack. Expose scheduled queue depth, failed counts, and retry age in your ops dashboard to catch incidents before campaign deadlines.

Troubleshooting

  • No active accounts matched: connect at least one active account for selected platforms.
  • OAuth callback fails: verify app credentials and registered callback URL.
  • No scheduled publishes: confirm cron executes every minute and timezone assumptions are correct.
  • Media upload errors: validate type and size constraints in package config.
