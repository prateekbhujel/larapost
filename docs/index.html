Unified API

Use SocialMedia::post() to publish or schedule posts across Facebook, Instagram, Twitter/X, and LinkedIn.

Safer Scheduling

Due posts are atomically claimed before processing to reduce duplicate publishes in concurrent worker environments.

Contributor Ready

1. Installation

Install the package in your Laravel application:

composer require prateekbhujel/laravel-social-sync
php artisan social-sync:install

If you prefer manual setup:

php artisan vendor:publish --tag=social-sync-config
php artisan vendor:publish --tag=social-sync-migrations
php artisan migrate

2. Required Environment Variables

SOCIAL_SYNC_DEFAULT_PLATFORM=facebook

FACEBOOK_APP_ID=
FACEBOOK_APP_SECRET=
FACEBOOK_API_VERSION=v20.0

TWITTER_CLIENT_ID=
TWITTER_CLIENT_SECRET=

LINKEDIN_CLIENT_ID=
LINKEDIN_CLIENT_SECRET=

Instagram uses Facebook credentials by default unless dedicated INSTAGRAM_* values are provided.

3. Usage

Immediate publish:

use SocialSync\Facades\SocialMedia;

$results = SocialMedia::post()
    ->content('New update from our Laravel app')
    ->platforms(['facebook', 'linkedin'])
    ->publish();

Scheduled publish:

SocialMedia::post()
    ->content('Scheduled campaign message')
    ->platforms(['facebook', 'twitter'])
    ->scheduleFor(now()->addHours(2))
    ->publish();

4. OAuth Account Connection

CLI flow:

php artisan social-sync:add-account facebook

Web endpoints:

  • GET /social-sync/connect/{platform}
  • GET /social-sync/callback/{platform}

5. Production Deployment

Add this cron entry for scheduled publishing:

* * * * * php /path/to/artisan social-sync:run-scheduled >> /dev/null 2>&1

Production checklist:

  • Run migrations before enabling scheduled posting.
  • Set all OAuth credentials in production .env.
  • Monitor failed posts and retry behavior.
  • Keep the package updated to the latest stable 1.x patch.

6. Troubleshooting

  • "No active accounts matched": connect at least one active social account for the selected platform.
  • OAuth callback fails: verify app credentials and callback URL in provider dashboards.
  • Scheduled posts not running: check cron output and confirm server timezone alignment.
  • Media posting issues: validate file size/type against package limits and platform constraints.
