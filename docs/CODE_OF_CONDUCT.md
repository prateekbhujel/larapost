# Code of Conduct

This project is committed to a welcoming and harassment-free experience for everyone.

## Our Standards

Examples of positive behavior:

- Respectful and constructive feedback
- Openness to different viewpoints
- Assuming good intent and asking clarifying questions

Examples of unacceptable behavior:

- Harassment, personal attacks, or discrimination
- Trolling, intimidation, or insulting comments
- Publishing private information without permission

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that violate this Code of Conduct.

## Reporting

Report incidents privately to `prateekbhujelpb@gmail.com`.

All reports will be reviewed promptly and handled confidentially.
