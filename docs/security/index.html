Reporting a vulnerability

Report unpatched vulnerabilities privately to prateekbhujelpb@gmail.com. Do not open a public GitHub issue for an unpatched vulnerability.

Include the affected version, reproduction steps or proof of concept, potential impact, and any suggested mitigation.

High-risk surfaces

LaraPost handles provider credentials and can publish externally. Treat these as privileged:

  • the operator dashboard
  • OAuth callback state and token exchange
  • queue workers and scheduled publishing
  • the optional MCP server
  • custom drivers that receive account credentials
MCP is disabled by default. Never expose it without authentication. Publishing and cancellation tools can create real external side effects.

Default protection

Operator routes use web and auth middleware by default. If an application replaces that middleware for tenancy or a custom admin guard, it remains responsible for ensuring the resulting route is restricted.

Run php artisan larapost:doctor after deployment or significant configuration changes; it reports when operator middleware needs review.

Response targets

  • Initial response: within 72 hours
  • Triage/update: within 7 days
  • Patch release: as quickly as practical based on severity
